# 旅行地图

给自己用的世界旅行地图。把想去的地点收进列表，按远近分成几天，再在地图上看每一天的顺序。地点之间的线只表示先后，还不是实际道路，也不估算交通时间。

地图和地点搜索使用 Mapbox。搜索用的是 Search Box 文本搜索，因为地理编码接口已经不返回寺庙、神社这类景点；令牌仍是下面这一个公开令牌。没有令牌也可以打开应用。

## 准备

电脑需要安装 [Node.js](https://nodejs.org/) 的 LTS 版本。

手机需要安装 **Expo Go**，并且支持 **Expo SDK 58**。本项目用的就是这个 SDK。如果打开后提示版本不兼容，到应用商店把 Expo Go 更新到最新版。

## 安装 Expo Go

1. iPhone：打开 App Store，搜索 **Expo Go**，安装 Expo 官方的应用。
2. Android 手机：打开 Google Play，搜索 **Expo Go**，安装官方应用。
3. 也可以从 Expo 的下载页进入：<https://expo.dev/go>

装好后打开一次，确认可以扫二维码。

## 配置 Mapbox 令牌

1. 打开 <https://account.mapbox.com/> 并登录。
2. 进入 **Access tokens**，复制一个 **public token**。公开令牌以 `pk.` 开头。
3. 在项目根目录复制示例文件：

   ```bash
   cp .env.example .env
   ```

4. 用编辑器打开 `.env`，把占位内容换成你的令牌：

   ```bash
   EXPO_PUBLIC_MAPBOX_TOKEN=pk.你的公开令牌
   ```

5. 保存后重新运行 `npx expo start`。改 `.env` 时，正在运行的 Expo 不会自动重新读取。

请只填写公开令牌。不要把以 `sk.` 开头的秘密令牌写进项目，也不要把它提交到 Git。`.env` 已经写在 `.gitignore` 里。可以提交的是 `.env.example`，里面只有占位符。

没有令牌时，应用仍然会打开。地图页会用中文说明原因，并按示例地点画出示意路线。

## 运行

在项目根目录执行：

```bash
npm install
npx expo start
```

终端出现二维码后，让手机和电脑连同一个 Wi-Fi，用 Expo Go 扫码。

也可以在终端里按 `w`，或直接运行 `npx expo start --web`，用浏览器看界面。浏览器和 Expo Go 都能搜索地点、编辑行程和看地图。

## 现在能做什么

- 搜索地点名称。结果会写出地名，以及当地、地区和国家。可以放进「想去的地点」，或直接加到当前这一天。同一个 Mapbox 地点，或名称和坐标都相同的地点，不会重复加入。
- 把攻略或帖子正文粘贴进来。应用会列出可能的地名，勾选并确认后才查找坐标。不会自动加入。
- 想去的地点和已经排好的地点可以按远近分成若干天，默认 3 天。先看预览，确认后才会替换现在的安排。之后可以调顺序、换到别的天、移回想去列表，或删除。
- 可以新增、重命名、删除某一天。至少保留一天。地图只画当前选中的那一天。
- 没有搜索结果，或还没配置令牌时，可以手动填写名称和经纬度。
- 行程保存在这台设备上，键名是 `travel-map.itinerary.v1`。没有账号，也没有服务器。没有保存过时，会看到京都半日的示例。已经改过的行程不会被示例盖掉，需要时可以手动恢复示例。
- 配置了有效的 Mapbox 公开令牌后，地图页会用 Mapbox 显示当前这一天。地点之间的连线只表示先后顺序，不是实际道路。
- 示例里的「40 分钟」「25 分钟」是写在数据里的占位数字，不是 Mapbox 算出来的。重新分配行程后，这些占位用时不会继续跟着走。

## 文件夹

- `src/app/`：页面。`index.tsx` 是地图，`itinerary.tsx` 是行程。底部标签在 `src/components/app-tabs.tsx`。
- `src/components/`：地图、地点列表和页面外壳。
- `src/state/`：行程的读取、保存和修改。数据存在本机，包括想去列表、多天安排和当前选中的一天。
- `src/data/sample-itinerary.ts`：第一次打开时用的示例地点。
- `src/types/itinerary.ts`：地点、一天、想去列表和示例用时的数据结构。
- `src/lib/mapbox.ts`：读取公开令牌。没有可用令牌时返回空。
- `src/lib/mapbox-search.ts`：用公开令牌搜索地点。
- `src/lib/extract-place-candidates.ts`：从粘贴的正文里抽出可能的地名。
- `src/lib/plan-days.ts`：按经纬度把地点分成几天，并排好一天内部的顺序。
- `app.json`：应用名称和 Expo 配置。
- `.env.example`：令牌变量名的例子。
